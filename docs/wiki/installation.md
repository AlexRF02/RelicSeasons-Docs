# Installation

## Requirements

- Paper 1.21.x
- Java version supported by your Paper server
- PlaceholderAPI and WorldGuard if you want their integrations

## Steps

1. Download the RelicSeasons plugin file.
2. Stop your server.
3. Place the plugin file in the `plugins` folder.
4. Start your server.
5. Review the generated configuration files.

## First Check

After startup, confirm that RelicSeasons loads without errors in the console.

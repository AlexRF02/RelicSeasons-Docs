# Weekly Curses

Weekly Curses are rotating server-wide challenges. They give each week a different atmosphere and encourage players to adapt their gameplay.

## Overview

A Weekly Curse is a temporary modifier or challenge that affects the server for a configured period.

The system is designed for seasonal SMP gameplay where the world feels alive and changes over time.

## How Weekly Curses Work

A typical Weekly Curse cycle looks like this:

1. Curse candidates are selected.
2. Players vote through the configured menu.
3. The vote is resolved.
4. One curse becomes active.
5. The curse remains active for its configured duration.
6. The system rotates again when the period ends.

Server staff can also force, clear, or resolve curses through admin commands when needed.

## Voting

Players can vote for the next curse when voting is enabled.

Voting can be controlled by permissions. Some servers may also grant higher vote weight to specific ranks.

Example vote weight permissions may include:

- normal vote access
- increased vote weight
- high vote weight

See [Permissions](../permissions.md) for the available nodes.

!!! note
    Vote weight should be used carefully. It can be useful for ranks or special events, but too much weight imbalance may make voting feel less community-driven.

## Active Curse

When a curse is active, it can affect gameplay depending on the selected curse type and configuration.

Possible curse behavior may include:

- increased danger
- special mob behavior
- world pressure
- progression challenges
- server-wide atmosphere changes

The exact effect depends on the configured curse.

## Rotation Timing

Weekly Curses are intended to rotate on a predictable schedule.

Server owners can configure the timing and should choose a rhythm that fits their server.

For example:

- weekly rotation for survival SMPs
- shorter rotation for test servers
- manual rotation for events
- longer rotation for slower seasonal servers

## Admin Control

Staff can manage the Weekly Curse system through admin commands.

Common actions include:

- check curse status
- set an active curse
- clear the active curse
- resolve the current vote
- rotate immediately

See [Admin Commands](../commands/admin.md) for exact command syntax.

## Recommended Usage

Weekly Curses work best when players understand that they are temporary.

Good usage examples:

- announce the active curse in Discord
- include curse status in server information
- connect weekly curses to events
- rotate curses on a consistent schedule
- use voting so players feel involved

## Configuration Notes

When tuning Weekly Curses, avoid making every curse equally punishing.

A good rotation should include different moods:

- dangerous weeks
- chaotic weeks
- economy-focused weeks
- exploration weeks
- combat weeks
- lighter weeks

This helps the system feel fresh instead of exhausting.

For general configuration structure, see [Configuration](../configuration.md).

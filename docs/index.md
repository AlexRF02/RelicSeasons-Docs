# Welcome

Welcome to the RelicSeasons Wiki. You can find all information about the plugin here.

## Features

- Eight unique relics with configurable progression.
- PvE and PvP energy systems.
- Secondary fragments.
- Weekly curses.
- Physical Ritual Altar.
- Cosmetic messages, effects, trails and auras.
- PlaceholderAPI support.
- WorldGuard support.
- Configurable menus and language files.

## Download

RelicSeasons will be available through the selected marketplace page.

## Suggestions

If you want to suggest changes or improvements, contact us through Discord.

## Reporting Bugs

Please report bugs with:

- Server version.
- RelicSeasons version.
- Steps to reproduce.
- Error logs if available.

## Dependencies

- Paper 1.21.x.
- Java 21.
- PlaceholderAPI optional.
- WorldGuard optional.
